# 阶段3：拆件

## 流程

1. **加载模型**：在Blender中导入GLB文件
2. **识别部件**：根据品类规则定位切割位置
3. **执行切割**：使用Boolean/Bisect操作分离部件
4. **后处理**：修复切面、添加榫卯结构
5. **导出**：各部件导出为独立STL文件

## 品类：公仔手办

标准部件划分及切割策略：

| 部件 | 切割方式 | 切割位置 |
|------|----------|----------|
| 头 (head) | 水平切割 | 颈部位置（模型高度约70-75%处） |
| 身体 (body) | 保留躯干 | 颈部到腰部之间 |
| 左臂 (arm_left) | 球形分离 | 左肩关节位置 |
| 右臂 (arm_right) | 球形分离 | 右肩关节位置 |
| 左腿 (leg_left) | 水平切割 | 髋关节位置（模型高度约35-40%处） |
| 右腿 (leg_right) | 水平切割 | 髋关节位置 |
| 底座 (base) | 生成 | 脚底下方添加圆形底座 |

## 执行

```bash
blender --background --python scripts/part_split.py -- \
  --input output/<project>/model.glb \
  --output-dir output/<project>/parts/ \
  --rules config/split_rules.yaml \
  --category figure
```

## 榫卯连接

每个切割面自动添加连接结构：
- **球榫**：用于手臂关节（可转动）
- **圆柱榫**：用于头部和腿部（可拆卸）
- **榫径**：3mm（默认，可在配置中调整）
- **公差**：0.2mm（适配3D打印/CNC精度）
